# NT21 NETWORK PRACTICE 80

NT21の配布資料と公認カンペをもとに再構成した、ネットワーク基礎の学習用静的サイトです。

公開サイト: https://felm4t4.github.io/nt21-network-practice-80/

- 全80問
- 説明問題30問
- 四択・計算・穴埋め・対応・読解を混在
- 初期表示は資料順と無関係にシャッフル済み
- 各解答に範囲、参照PDF名、PDFページ番号を表示
- 学習進捗をブラウザのローカルストレージへ保存
- 検索、形式フィルター、再シャッフル、一括解答表示、印刷に対応

## 正確性について

配布PDFはテスト範囲ノートとして扱い、空欄は公認カンペと一般的なネットワーク知識で補完しています。旧来のサブネット計算、MACアドレスの不変性、Token Ringの位置付け、全二重EthernetにおけるCSMA/CDなど、現在の標準と差がある箇所は解答内で区別しています。

補完確認にはRFC 1918、RFC 4632、RFC 1878、RFC 826、RFC 1122、RFC 3021、RFC 792、およびIEEE 802.3の公式情報を利用しています。

## 公開方針

元の配布PDFそのものは、このリポジトリへ含めていません。公開物は派生した問題・解答・参照情報のみです。

## ローカルで開く

`index.html` をブラウザで開くだけで利用できます。外部ライブラリやビルド処理は不要です。
