# NT21 ネットワーク演習80問 - 授業範囲版

NT21の配布資料と公認カンペにある用語・基本事項だけで復習する、学習用静的サイトです。

公開サイト: https://felm4t4.github.io/nt21-network-practice-80/

- 全80問
- 説明問題30問
- 四択・計算・穴埋め・対応・並べ替え・正誤を混在
- 初期表示は資料順と無関係にシャッフル済み
- 各解答に範囲、参照PDF名、PDFページ番号を表示
- 学習進捗をこの端末へ保存
- 検索、形式フィルター、再シャッフル、一括解答表示、印刷に対応

## 今回の改訂

授業で扱っていない内容へ広げすぎた設問・選択肢・解説を見直し、資料にある内容の確認を中心にしました。説明問題は意味・違い・理由を1〜2点答える内容、計算問題は基本的な手順を確認する内容です。外部資料による専門用語や発展事項の追加は行っていません。

空欄は公認カンペの説明で確認しています。計算方法が指定されている問題では、問題文に示した資料の計算方法を使ってください。参照欄のページはPDFファイルの先頭から数えた番号です。

問題内容を変更したため、習得記録は改訂版用に別保存します。旧版の記録は削除しません。

## 公開方針

元の配布PDFそのものは、このリポジトリへ含めていません。公開物は派生した問題・解答・参照情報のみです。

## ローカルで開く

`index.html` をブラウザで開くだけで利用できます。外部ライブラリやビルド処理は不要です。
